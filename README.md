# אתר ZULATECH

אתר תדמית לעסק שירותי מחשבים, תקשורת, חשמל ומצלמות אבטחה - חדרה, השרון וחיפה.

## סטק טכנולוגי

- **Astro 7** - מייצר HTML סטטי (SSG) לכל עמוד
- **Tailwind CSS 4** - עיצוב

## הרצה מקומית

```bash
npm install      # התקנת תלויות (פעם אחת)
npm run dev      # שרת פיתוח - http://localhost:4321
npm run build    # בניית האתר לתיקיית dist/
npm run preview  # תצוגה מקדימה של הבנייה
```

## מבנה הפרויקט

```
src/
├── data/site.ts              הגדרות מרכזיות: טלפון, כתובת, ניווט
├── styles/global.css         מערכת העיצוב: צבעים, פונטים, אפקט זכוכית
├── layouts/BaseLayout.astro  שלד העמוד
├── components/
│   ├── Header.astro          תפריט עליון + תפריט מובייל נגלל
│   ├── Footer.astro          פוטר
│   ├── FloatingActions.astro כפתורים צפים, נגישות, באנר עוגיות
│   └── Faq.astro             אקורדיון שאלות ותשובות
└── pages/                    כל קובץ כאן = עמוד באתר
```
